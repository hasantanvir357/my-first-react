## 📌 Overview

This project is a high-performance frontend product management interface. It demonstrates smooth asynchronous data fetching using React 19 features, full TypeScript type safety, and efficient state management for cart interaction. Users can seamlessly add items, manage quantities incrementally, and clear their selection.

---

## ✨ Features

- **Interactive Cart Management**: Add products to the cart with real-time quantity indicators.
- **Unit Controls**: Dynamically increase (`+`) or decrease (`-`) individual product quantities directly from the product card.
- **Global Cart Reset**: Reset the entire cart state with a single click.
- **Asynchronous Data Handling**: Uses React's `use` API to stream dynamic product data via Promises.
- **Fully Responsive**: Styled with Tailwind CSS for optimized viewing across desktop, tablet, and mobile screens.
- **Type-Safe Codebase**: Strict TypeScript types prevent runtime type errors.
